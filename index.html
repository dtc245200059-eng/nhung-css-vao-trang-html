[Bài tập] Nhúng CSS vào trang HTML

Khám phá và phân biệt 3 cách định kiểu CSS: Inline-style, Internal-style và External-style

Phần 1: Inline-style

Tiêu đề văn bản: Định dạng màu sắc bằng Inline-style

Đoạn văn này được định dạng màu đỏ thắm bằng cách nhúng thuộc tính style="color: #be123c;" trực tiếp vào trong thẻ <p>. Phương pháp này có độ ưu tiên cao nhất nhưng khó tái sử dụng khi website lớn.

<!-- Cú pháp Inline Style -->
<h2 style="color: #e11d48;">Tiêu đề...</h2>
<p style="color: #be123c;">Đoạn văn...</p>
Phần 2: Internal-style

Tiêu đề văn bản: Định dạng màu sắc bằng Internal-style

Đoạn văn này được định dạng màu xanh dương bằng cách sử dụng thẻ <style> đặt trong phần <head> của trang HTML. Phương pháp này giúp tập trung các quy tắc định kiểu cho một trang đơn lẻ.

<!-- Khai báo trong thẻ <head> -->
<style>
  .internal-heading { color: #2563eb; }
  .internal-paragraph { color: #1e40af; }
</style>
Phần 3: External-style

Tiêu đề văn bản: Định dạng màu sắc bằng External-style

Đoạn văn này được định dạng màu xanh ngọc bích thông qua tệp CSS độc lập bên ngoài (style.css) và được liên kết bằng thẻ <link rel="stylesheet" href="style.css">. Đây là phương pháp tiêu chuẩn tốt nhất trong phát triển web thực tế.

<!-- Trong tệp HTML: <link rel="stylesheet" href="style.css"> -->
/* Trong tệp style.css */
.external-heading { color: #059669; }
.external-paragraph { color: #065f46; }

So sánh tổng quan 3 phương pháp nhúng CSS

Phương pháp Vị trí viết mã Độ ưu tiên Ưu điểm Trường hợp áp dụng
Inline-style Thuộc tính style trên thẻ HTML Cao nhất (1000) Tác động tức thì, thử nghiệm nhanh Thử nghiệm nhanh, override tạm thời
Internal-style Thẻ <style> trong <head> Trung bình (phụ thuộc thứ tự) Quản lý tập trung trong 1 trang duy nhất Trang đơn (Landing page, email template)
External-style Tệp riêng biệt (ví dụ: style.css) Tiêu chuẩn (dễ ghi đè) Tái sử dụng cho toàn website, tải nhanh (cache) Dự án thực tế chuyên nghiệp
